# Ashling copies the sacrificed Elemental

Ashling, the Limitless's sacrifice trigger previously copied Ashling when another nontoken Elemental was sacrificed. Its copy-of-it action used a generic parameter bound to the ability holder. The action now uses the existing `ThatSacrificedPermanent` parameter, separately from the holder, and emits `Trigger_ThatSacrificedPermanent`. Lowering produces the sacrifice event's original object, `EventSubject`.

The holder binding remains necessary for “another target creature” on Jenny Flint and Lonis, Genetics Expert. Both real cards and a synthetic trigger explicitly naming “this creature” are negative controls. The corrected copy phrase is routed through the established sacrifice-action family; there is no card-name rule and no public source/IR schema change.

Fresh parsing changes exactly Ashling's copy operand. All other source records remain identical, including Jenny and Lonis. The full IR comparison likewise changes only `tokens[0].recipe.Copy.object`, preserving the Elemental/nontoken event filter, token recipient, copy information policy, haste, delayed end step, mana payment and actual-created-token sacrifice operands.
