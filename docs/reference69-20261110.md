Ranar/Hero's grouping decision uses CR603.1–603.2c and the original once-per-
simultaneous-exile ruling together with the June2021 update: that update changes
which exile causes qualify, not the written ability's ownership. This is a rules
interpretation backed by structural tests, not a newly executed engine ruling.
A mixed-origin witness is Ranar enchanted by One with the Stars surviving Decree
of Annihilation while an artifact and a hand card are exiled simultaneously.
Two separate native ability owners would produce two Spirit triggers. No
comparison alias equating those representations is introduced.

## Corrections to earlier advice

Mirror Shield's original Source Trigger_ThatCreature was correct. The first
participant is the deathtouch creature in both combat directions. Restore that
Source and fix the Rust binding to EventSubject; explicit attacking/blocking
references continue to use fixed combat roles. Our recommendation to use Other
in #81 was wrong.

Bronze Bombshell's original Trigger_ThatPlayer was also correct. Owner A,
controller B: the trigger captures B. If C takes control before resolution, B
cannot sacrifice C's permanent, so that trigger does no damage. Reading the live
controller incorrectly makes C sacrifice. StateWithPlayer makes this capture
explicit. Our live-controller recommendation in #82 was wrong.

Both reports contain other findings; correct the mistaken entries without
closing their remaining findings.
