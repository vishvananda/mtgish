# Rejected report 170 and partly accepted report 172

## 170: keep the implicit player choice

The maintainer [clarified APlayerMayAction](https://github.com/i5jb/mtgish/issues/170#issuecomment-6885104952):
it includes a ChooseAPlayer by the ability controller. The selected player then
decides whether to perform the optional action. PlayerMayAction has a specified
player, EachPlayerMayAction applies to every player, and AnyPlayerMayCost lets
the offered players decide whether to pay; these policies are distinct.

We never changed Stardew Valley's English template or cached Source in response
to the report. Its retained APlayerMayAction form is correct. Current PlayersDo
lowering retains any_one and optional. The existing backend chooses the doer
using the original controller, then enters that doer's local action frame for
acceptance and the control recipient. The preceding draw remains in the
original frame. A new full-card regression verifies both AST policy and the
order of those generated decisions. No Source revert or AST change is needed.

## 172: keep the search constructor, correct the arithmetic

The maintainer [accepted the reversed subtraction and rejected the constructor change](https://github.com/i5jb/mtgish/issues/172#issuecomment-6885300255).
Our Source still used FindNumberCardsOfType, so there was no constructor change
to undo. Our existing private-library lowering already gives this matching-card
search Count::UpTo, consistent with failing to find. Preserve that lowering.
This does not make an unqualified request for generic cards optional: its
existing Count::AsManyAsCan stays, with a regression for the distinction.

Scholarship Sponsor now computes the captured maximum number of lands minus
the searching player's land count. The adjacent reveal/hand template on Enigma
Ridges has the same reversal and receives the same correction. Their captured
maximum, eligibility, player identities, basic-land filter, destinations,
tapped entry, reveal and shuffle stay intact.

The adjacent Boreas Charger template instead measured both players' hands.
It now counts the chosen opponent's battlefield lands minus your battlefield
lands. It retains the opponent choice, Plains, reveal, one tapped battlefield
arrival, remaining hand arrivals and shuffle. Sandstone Oracle and Slithermuse
really compare hand sizes and remain unchanged. The current upstream English
blob b562a2961353cbb032849a6c211884cd4e8554cb was checked independently.

All fixes use schema 191's existing expressions and search policy. No portable
AST fields, numeric widths, engine capabilities or browser workspaces change.
The follow-up source/AST export changes only these three cards relative to the
0.2.1 adoption commit. The other 33,526 records remain byte-identical, including
Stardew Valley and the hand-size controls. Fresh parsing reproduces all 33,529
cached Source records; all 182 reviewed audit findings, including complete
matched usage evidence, are identical and no new unresolved finding appears.
